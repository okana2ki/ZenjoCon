# ZenjoCon
Codexによる全国情報教育コンテスト応募支援のためのレポジトリ

## 使用手順
1. 事前準備
Codexを初めて使う方は、[hello-codex](https://github.com/okana2ki/hello-codex)の[事前準備](https://github.com/okana2ki/hello-codex/blob/main/%E4%BA%8B%E5%89%8D%E6%BA%96%E5%82%99.md)を見て、以下の準備を行って下さい
    1. ChatGPTデスクトップアプリのインストール
    2. Codex権限の設定
    3. 練習プロジェクトの作成と動作確認
2. [ZenjoConレポジトリ](https://github.com/okana2ki/ZenjoCon)のダウンロード
    1. レポジトリのページ右上部 緑色の「Code」ボタンをクリック
    2. ドロップダウンメニュー一番下の「Download ZIP」をクリック
    3. ダウンロードしたファイル `ZenjoCon-main.zip` を解凍
    4. 解凍したフォルダ `ZenjoCon-main` を適当な場所に置く
3. Codexを起動し、新規プロジェクトを作成
    1. プロジェクト名を入力（例；全情コン応募）
    2. ソースフォルダの追加：`ZenjoCon-main` の下の :**`全情コン応募支援`フォルダをソースフォルダに追加**
4. [「全情コン応募支援」の下のREADME.md](全情コン応募支援/README.md) に従って、演習を進める

## 解説（このレポジトリの作り方）
- 最初に[このプロンプト](prompt.md)で、Codexに、コンテスト応募支援レポジトリの設計方針を相談したのが始まり。その後、いろいろな改良を加えました。
- Codexが高校生をどう支援するかという方針が、`全情コン応募支援/AGENTS.md`に書かれています。AIが自動生成したものに人が手を加えています。
- `contents`フォルダ中のコンテストに関する情報が、`knowledge`フォルダ中の3つのマークダウン（コンテスト要点、審査基準、応募項目）に要約されています。これはほぼ自動生成されたまま使っています。応募支援の時点では、Codexはこの要約された情報から必要な情報だけを読み、元の`contents`フォルダの情報にはアクセスしないという設計により、無料の範囲で支援ができる可能性を増やしています。なお、決められたフォーマットに合わせる必要がある応募書類案への講評も可能にするため、応募用紙だけは応募用紙そのものも参照できるように`contents`フォルダに入れてあります。
